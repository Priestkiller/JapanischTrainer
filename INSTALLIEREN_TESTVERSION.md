# JapanischTrainer Testversion 11 0 7 installieren

Windows: Setup für die Erstinstallation; vorhandene Installation unter Einstellungen → Programm-Updates → **Testversion suchen** bewusst aktualisieren. Das kleine Update verwendet die vorhandenen Modelle weiter. Der Installer hat weiterhin kein Authenticode-Zertifikat; Update-Metadaten werden mit dem bisherigen Ed25519-Schlüssel geprüft.

Android: signierte APK bewusst herunterladen und **über die vorhandene App installieren**. Nicht deinstallieren. Paket de.priestkiller.japanischtrainer, Version 11.0.7-android.1-test, Code 11000701. Der Signierschlüssel bleibt gleich. Vorhandenes Offline-Sprachpaket und Lernstand bleiben bei der Aktualisierung erhalten. Sicherung vor dem Test unter Einstellungen exportieren. Zum Sprechen wird weiterhin das einmalige bestehende Sprachpaket benötigt.

Einstieg: Eine freigeschaltete Pilotlektion öffnen und **Abwechslungsreich üben** wählen. Eine Liste aller 25 Lektionen steht in UEBUNGSVIELFALT_UMSETZUNG.md. Einführung lesen/anhören, dann Zusatzrunde starten. Hilfe und Pause sind erlaubt. Zusatzaufgaben ersetzen keine offenen Pflichtschritte und geben keine zusätzlichen XP.

Dies ist ein Prerelease. Die stabile 11.0.4 wird nicht ersetzt; die normale Updatesuche bietet diese Ausgabe nicht an. Die App lädt oder installiert nichts automatisch. Menschliche Sprachprüfung, Anfänger-Erprobung und echte S24-Ultra-/Mikrofon-/Hörtests sowie frisches Windows-System bleiben offen; siehe GERAETEPRUEFUNG_11.0.7.md.
